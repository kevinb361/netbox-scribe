Characterized gaps in the new checker, none of which is a live defect at `HEAD` (see AUDIT.md **N1**–**N6**):
it validates filesystem existence rather than tracked-ness, so a link to an untracked or absolute local path
passes locally while 404-ing publicly; it flags Markdown links inside fenced code blocks; it does not parse
reference-style or raw-HTML links; `scripts/` is outside `mypy`'s configured scope; and it raises an
uncaught traceback outside a Git checkout.
