# Roadmap: NetBox Scribe

## Milestones

- ✅ **v0.1 First Useful Snapshot** — shipped 2026-07-21 (8 REQs; installable CLI exports deterministic, validated, AI-ready device context from a read-only NetBox API)
- ✅ **v0.1.0 Release Hardening** — shipped 2026-07-21 (1 REQ; encrypted token transport required by default, independently audited, and release-ready)
- ✅ **v0.1.1 Public GitHub Readiness** — shipped 2026-07-21 (public-safety audit, least-privilege GitHub CI, security/contribution policy, and operator-gated publication handoff; independently audited PASS)
- 📌 **v0.2 Network Relationships** — pending follow-up: add prefixes, VLANs, interfaces, addresses, cables, VMs, and partitioned relationship-aware views
- 📌 **v0.3 Agent Delivery** — pending follow-up: add bounded context packs, change digests, retrieval evaluation, and an optional static-snapshot MCP surface
- 📌 **v0.4 Enterprise Hardening** — pending follow-up: prove large-inventory scaling, throttling, compatibility policy, observability, and deployment recipes
